Проверяем подключение...

Как проверить

Открой DevTools (F12) → вкладка Console. Выполни:

fetch('/api/orders').then(r => r.json()).then(console.log)

Должен вернуться массив заказов.

Управление моком из консоли

MockApi.setDelay(2000, 3000)   // задержка 2–3 сек
MockApi.setErrorRate(1)        // все запросы 500
MockApi.setNetworkDown(true)   // нет сети

// вернуть нормально:
MockApi.setDelay(300, 800)
MockApi.setErrorRate(0)
MockApi.setNetworkDown(false)

Полезные тесты

// список заказов
fetch('/api/orders').then(r => r.json()).then(console.log)

// один заказ (проверка :id)
fetch('/api/orders/101').then(r => r.json()).then(console.log)

// фильтр
fetch('/api/orders?status=cooking').then(r => r.json()).then(console.log)

// блюда
fetch('/api/dishes').then(r => r.json()).then(console.log)

// статистика
fetch('/api/stats').then(r => r.json()).then(console.log)

// создать заказ (POST)
fetch('/api/orders', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    clientId: 1,
    comment: 'Тест',
    items: [{ dishId: 1, dishName: 'Борщ', quantity: 2, price: 350 }]
  })
}).then(r => r.json()).then(console.log)
